About Me

Saya memilih jurusan ini karena saya memiliki passion yang cocok dan yang saya inginkan. Misalnya seperti dalam pembuatan website berbasis bahasa pemrograman HTML dan CSS. Tak hanya itu saya sebagai Programming masih belajar juga mengenai bahasa pemrograman java dan python
